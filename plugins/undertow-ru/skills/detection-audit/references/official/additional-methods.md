# Дополнительные методы выявления

Этот файл содержит только дополнительные методы, прямо описанные в методичке.

## Альтернативные источники местоположения

В разделе `5.5. Альтернативные источники определения местоположения устройства` указаны:

- местоположение по идентификаторам базовых станций мобильной сети (`PLMN`) или по Wi-Fi точкам доступа (`BSSID`) с последующим обращением к GeoIP;
- координаты из приложения при наличии согласия пользователя на геолокацию;
- координаты не заменяют проверку GeoIP, а дополняют ее и снижают число ложноположительных срабатываний;
- координаты не доказывают отсутствие VPN.

## Анализ задержек (SNITCH)

В разделе `10.1. Метод анализа задержек` указано:

- метод `SNITCH` (Server-side Non-intrusive Identification of Tunnelled Characteristics) не требует внешних сервисов;
- измеряется `RTT` между сервером и клиентом;
- через VPN трафик идет в обход, через VPN-сервер, что вносит дополнительную задержку;
- геолокация IP сопоставляется с задержками до контрольных точек (`landmarks`);
- аномально высокая задержка для заявленной геолокации IP указывает на VPN.

## Анализ HTTP-заголовков

В разделе `10.2. Анализ HTTP-заголовков` указано:

- заголовки `X-Forwarded-For`, `Forwarded` или `Via` могут указывать на промежуточный proxy-узел;
- признак использовать с осторожностью: сервис или CDN может легитимно формировать часть таких заголовков.
